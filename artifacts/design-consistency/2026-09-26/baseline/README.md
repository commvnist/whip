# Settings navigation baseline at 900dp

Captured on the disposable Android 34 emulator at 1080px width and 192dpi (900dp), before the sidebar unification.

- `settings-900dp-split.png`: Open Settings from the split Home workspace. The support pane shows descriptive rectangular section cards.
- `settings-900dp-expanded.png`: Expand the Home content pane, then open Settings. The same six sections use title-only drawer pills, demonstrating the reachable visual inconsistency.

These captures preserve the prior appearance for comparison with the shared section-card implementation.
