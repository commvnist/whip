# Whip live UX audit — 2026-08-21

## Scope and method

This pass audited the installed app rather than relying on checked-in product
screenshots. The inner Fold display was reviewed across Home, all six Task
destinations and three planning views, all four Habit destinations, all four
Goal destinations, all four Gym destinations, the five Gym Library children,
and all four Settings sections. The baseline captures are in
`artifacts/ux-audit/2026-08-21/before/open/`; the release recapture is in
`artifacts/ux-audit/2026-08-21/after/open/`.

The cover-display pass must be captured only after the phone is physically
closed and unlocked. Remote fold-state simulation and on-device instrumentation
are deliberately excluded because they can invoke Samsung lock handling. Local
unit, compile, and lint checks remain safe; phone verification is limited to
ordinary app interaction and screenshots.

## Resulting interaction grammar

- Underlined tabs switch peer destinations. Their outer gutters stay fixed, and
  the strip moves only enough to reveal a selected tab that was clipped.
- Segmented controls switch alternate views of the current destination.
- Search/filter/select controls stay attached to their temporary content.
- Down arrows open value menus; up/down chevrons reveal optional content;
  right chevrons open child pages; vertical ellipses contain secondary actions.
- Dense configuration remains available without competing with the default
  workflow.
- Empty screens explain the state once and offer one next action.
- Primary color communicates selection or action; neutral outline color
  communicates structure and separation; error color remains reserved for
  destructive or invalid states.
- Visible action and selection surfaces use rectangular corners instead of
  pills. Shape-bearing indicators such as color swatches, checkboxes, switches,
  and progress indicators retain their conventional geometry.
- Action-button content is centered as a complete group. Text fields,
  dropdowns, disclosures, and navigation rows use leading text with a trailing
  affordance rather than pretending to be centered actions.
- Page titles, destinations, menus, and commands use Title Case. Field labels,
  supporting copy, full sentences, and user-authored names remain sentence case.
- A control that changes the meaning or availability of later settings owns the
  next block: consequence first, dependent settings second, unrelated settings
  only after that block. Disabled controls always state what unlocks them.

## Regression coverage

- Destination tabs retain their 20 dp starting position when the final visible
  tab is selected and remain reachable at large text in RTL.
- Task Filters open a focused dialog; Search and Select reveal content directly
  beneath their controls; quick capture retains its review explanation.
- Gym History and Progress hide optional controls initially and reveal them from
  their named disclosure rows.
- Android Back from a Gym Library child returns to Library.
- Visual-language tests enforce one accent family, the rectangular corner
  scale, neutral divider/error roles, and use of shared action wrappers so a
  screen cannot accidentally restore Material's pill defaults.
- Toolbar UI coverage measures each action's content-group center against the
  control center, including icon-plus-text and text-only variants.
- Editor dependency coverage asserts that task repeat rules occur before
  planning fields, weekday reminders start empty, disabled cadence choices
  explain how to unlock them, and the shared dependency notice exposes an
  accessibility description.
