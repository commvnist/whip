## Emerging findings (not final scope)

- Habit history editing can rewrite check-off/checklist outcomes or numeric failed status; date editing lacks the creation future-date boundary. Agent tracing invariants and callers.
- Habit additive entry pre-fills an existing total; a note-only edit can inadvertently log that number again. Agent tracing input modes and repository semantics.
- Gym graph point resolution uses date and display name instead of exact session/exercise identity; duplicate dates/names can open a different record. Agent tracing selection and aggregate drill-down.
- Search history caps are distinct from its result-count cap; omitted older Habit/Goal/Track content is currently not disclosed as partial results. Parent tracing index construction and incomplete-result presentation.
- Short-window inspector and long error-state reachability require native reproduction; previous untested assumptions are explicitly reopened.
