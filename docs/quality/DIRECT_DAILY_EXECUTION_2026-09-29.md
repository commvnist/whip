# Direct daily execution — 2026-09-29

FB-20260929-018 requires eligible daily work to be executable on the visible item without opening an inspector or expanding its details. Baseline `ecdb3eee`. Parent integrates shared/Home/planning/Gym; the same authorized GPT-6.1 Sol/high Tasks, Habits and Goals component agents implement their owned surfaces. This is implementation scope following the separate full component audit.

## Interaction rule

Execution controls remain visible. Supplemental description, history, analysis and configuration can remain under disclosure. A specified check-off, checklist item, milestone or preset amount uses the existing exact mutation. An action requiring a value, duration choice or consequential lifecycle confirmation opens that focused form directly. It does not first open the item inspector. Current dates, occurrence identities, schedules, paused/archived states, timer recovery, conversion/history and request receipts remain authoritative.
