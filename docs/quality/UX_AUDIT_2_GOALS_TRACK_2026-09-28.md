Labels: **Confirmed** means a traceable source contradiction; **Keep** means a deliberate behavior re-evaluated in this pass; **Coverage gap** means evidence is insufficient for a pass or a production defect. P1 affects data interpretation or a workflow; P2 affects discoverability, reachability or feedback. No storage migration, authored-history rewrite, new recurrence engine or generic analytics architecture is proposed.

## Intentional limits and reconciliation

- The previous keep of numeric Insights is revised because its **domain construction**, not its new visual hierarchy, ignores authored windows. Likewise previously accepted readonly type facts in Track are retained while Goal's contradictory editable dimension is corrected.
- Preserving closure storage contracts means old snapshots do not gain invented measurement metadata. New guards prevent future reinterpretation; already ambiguous legacy snapshots cannot be reconstructed confidently from present source and require honest presentation/explicit recorded-value qualification.
- Global search history caps and shared search unit labels are parent-owned; the reusable Track title helper coordinates the latter. Shared input sizing, inspector geometry, permission dialogs and Area/Tag behavior are not duplicated here.
- New Start Date is an explicit authoring boundary, not recurrence or a migration. Exact elapsed Counter Start remains separate. Its native large-text/keyboard placement must be inspected before accepting the UI.
- No fresh TalkBack traversal, accessibility-service session, very long milestone stress run or full catalog rerun has occurred. Those claims remain unverified; selected semantic and 200% device checks will provide a bounded acceptance record, not blanket certification.
- Parent records implementation approval, final integrated totals and retained fresh evidence. This document must not mark pending native checks passed merely because baseline methods passed yesterday.
